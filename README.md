# ４次元不変母体宇宙論
## 4D Invariant Matrix Cosmology

### はじめに
宇宙の基本公理は、驚くほどシンプルです。<br>
​「エントロピーの均一化が波動として伝播する」これだけです。<br>
この考えをもとに宇宙を考察していくとひとつの公理にたどり着きます。<br>
​「存在するもの（物質）、作用するもの（力）、そして変化（時間・空間の進み）のすべては、不変母体空間における『エントロピー均一化の波動』の異なるあらわれ（モード・干渉・スペクトラム）に過ぎない」<br>
過去から未来まで詰まっている４次元空間「不変母体空間」にある「波動」が宇宙のすべてを説明できる。<br>
そんな話です。<br>
